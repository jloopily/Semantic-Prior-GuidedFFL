# M1.1 C2 空间位置与 gallery 候选数量去混杂：实验记录

> **记录性质：**对下载并解压的服务器审阅包作只读检查。数值来自冻结产物；本文另外核对了原始逐视频表、M1 上游文件哈希、压缩包校验和以及部分 bootstrap 数组的百分位数。未在本地运行模型、重算原始 kNN、修改评分器或改动服务器结果。记录中的 `C2_SIGNAL_BUT_SPATIAL_OR_GALLERY_CONFUNDED` 是冻结程序给出的决定，不代表已证明某一个具体混杂机制。

## 1. 问题与冻结设计

M1 的主评分器 `r_k` 未获得静态定位支持；次级 C2 在 fake 与配对 real 的虚拟 mask AP 差值上有正信号，但面积基线和真实脸空间模板对照不支持将其直接解释为伪造定位。M1.1 因此只对 **C2** 审查空间位置及 gallery 候选数量因素，不是事后更换主评分器的救援实验。

固定条件：

- **A：**`full_unrestricted`，完整 real c23 gallery，64 视频 × 每视频 784 token = **50,176** 候选；沿用 M1 C2 分数，作为完整图库描述性参照。
- **B：**`same_token_index`，每个 gallery 视频取与 query 相同的 28×28 网格位置，**64** 候选。
- **C：**`matched_count_unrestricted`，每个 gallery 视频取一个预先固定的随机位置 token，**64** 候选；完整报告五个预定 seed：`20260929`、`20260930`、`20260931`、`20260932`、`20260933`。先对同一视频的五 seed 指标求均值，再作主汇总；不挑选有利 seed。

B 与 C 在候选数量上可配对比较；**A 与 B/C 的候选数量不同，不得把 A−B 或 A−C 直接解释为纯空间效应。**这里的“同位置”指 crop 的网格坐标相同，不等于精确的解剖部位配准。

所有条件沿用 C2 公式、异常高分方向、`k=20`、28×28 token 热图及 448×448 双线性上采样。冻结 validation T3 帧、四类 manipulation、既有配对和 mask 定义不变。各条件阈值由其 validation real c23 像素分数按第 99 百分位校准（linear，严格 `>`）；c40 使用该条件的 c23 阈值，不在 c40 重校准。统计为每视频合并 T3 帧像素计算指标、四类 manipulation 等权平均；对 **70 个 source group** 作 **2,000 次**有放回 bootstrap，各条件共享相同抽样索引。

主要比较量：`U = fake Pixel AP − fake mask 阳性比例`；`D = fake Pixel AP − 配对 real 在同一虚拟 mask 下的 AP`；辅助 `R = mask 内平均(fake−real 分数) − mask 外平均(fake−real 分数)`。空间模板对照为 fake AP 减去由 real c23 生成的位置模板在相同 fake mask 下的 AP。AP 差值是绝对 AP 单位，不是相对百分比。

A c23 的预定 **97.5% CI**：U 为 `[−0.00218, +0.02574]`，D 为 `[+0.01953, +0.03091]`。A 的 D 是正值，但 U 点估计 **+0.01100 < +0.02**，且更严格区间的下界不大于零。因此不能只引用 D 正值宣称达到继续条件。

B−C 在同样 **64 候选**下的 c23 配对 D 差为 **+0.01894**，95% CI `[+0.01463, +0.02341]`；c40 为 **+0.01686**，95% CI `[+0.01260, +0.02090]`。这表明两个候选集合/位置策略产生不同结果，但不证明唯一原因是某个面部解剖位置。

C 的五个 c23 单 seed D 点估计依次为 **−0.00387、−0.00191、−0.01637、−0.00199、−0.00231**，没有按结果选择 seed；五 seed 视频均值 D 为负。A c40 沿用 c23 阈值时，real 像素加权 FPR 为 **0.01785**，是压缩转移检查，不是独立测试集验证。

## 4. 冻结决定与解释界限

服务器给出的决定为 **`C2_SIGNAL_BUT_SPATIAL_OR_GALLERY_CONFUNDED`**。`decision.json` 所列失败原因逐项与结果吻合：

1. A c23 的 U 未满足预定幅度和 97.5% 区间条件；
2. B/C 同候选数比较中，五 seed 平均的 C D 为负，五个单 seed D 点估计也全部为负；
3. A 的 fake AP 低于仅基于 real 数据建立的空间模板 AP，c23 差值为负。

正向的 A D 和 R 应如实保留，但不覆盖上述失败门槛。B−C 差异说明候选位置策略不能忽略；A 相对 B/C 又同时改变候选数，不能分解出唯一因果机制。M1 主评分器 `r_k` 不因此转为成功；原 Synthetic Gate B 继续 `FAIL`，M0 仍为暂定结构审计。FF++ validation 已在此前轮次使用，本轮是**探索性**检查，不是未见数据上的独立确认，更不能推出跨数据集有效、真实人脸流形或法向伪造机制。

## 5. 审阅范围与未完成事项

- 本地下载的是**精简审阅包**：未含 `raw_knn/` 和 `per_token_scores/` 的原始距离/索引、token 分数数组；`score_indices/` 等文件可定位服务器原始数组，但其服务器绝对路径不是本地可读取文件。因此本审阅**无法独立从原始 kNN 数组重算全部 B/C 分数和模板**。如以后需要逐 token 的端到端核验，须另取完整原始包及上游 feature/gallery 数组。
- `diagnostics.json` 中 `mask_placement_control=skipped_existing_implementation_unavailable`；未执行 mask 位置扰动对照，不可写成已排除 mask placement 混杂。
- 审阅包未包含可供逐阶段交叉核查的 M1.1 运行日志、完整服务器代码快照或 Git commit ID。冻结/未访问 test 等声明有产物支持，但不构成对服务器全过程的独立取证。
- c23 real 第 99 百分位阈值是在同一 validation real 子集上校准的；这部分 real FPR 不应当作留出集性能。
- 原始 M1 无定义 mask 视频的 F1/IoU 数值与 M1.1 的缺失值处理口径有轻微差别；涉及这些阈值指标时应写明各自的有效支持域，不应混算。

## 6. 最终可用表述与后续边界

**可用表述：**“在 validation-only 的 M1.1 C2 定向审查中，完整图库相对配对真实脸的 c23 AP 差值为正，但对 mask 面积基线的增益不足且区间跨零，真实脸空间模板对照更强；同样 64 候选的两种位置策略结果明显不同，五个固定随机 seed 的 unrestricted 对照未维持正的配对增益。因此 C2 作为无混杂静态伪造定位器未获支持。”

**不可用表述：**“M1.1 通过”“已排除空间位置和图库候选数混杂”“已证明异常来自伪造区域”“验证了原始 CIR-LID 的流形机制”。保留冻结结果与所有 seed，不事后修改 C2 公式、方向、mask、数据范围或阈值；**official test 继续锁定，不自动启动下一轮实验**。
